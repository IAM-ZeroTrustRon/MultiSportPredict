## 1. TWO SOCCER STORES DISAGREE ABOUT WHAT A NUMBER MEANS

**This is the most damaging thing in the repo. Fix it before running soccer.**

`get_soccer_team_stats()` reads `data/soccer_stats.json` first, then falls back
to `data/team_stats/soccer_stats.json`. The two files use the same field name
for different quantities:

```
GLOBAL  data/soccer_stats.json          goals_for is a PER-GAME RATE
          Bournemouth   goals_for = 1.0     games = 1
          Napoli        goals_for = 1.314   games = 1

MANUAL  data/team_stats/soccer_stats.json   goals_for is a SEASON TOTAL
          AC Milan       goals_for = 6     xg_for = 1.45   games = (none)
          Bayern Munich  goals_for = 14    xg_for = 2.45   games = (none)
```

Within a single manual record, `goals_for` is a total and `xg_for` is a rate.

**16 clubs exist only in the manual store**, so for those the fallback is not a
fallback — it is the data:

```
AC Milan, Ath Madrid, Bayern Munich, Bradford City, Dinamo Zagreb,
Inter Milan, Lumphat SC, Newcastle United, Nongrah, Real Madrid,
Real Sociedad, Salernitana, ...
```

The model reads `goals_for = 14` for Bayern and treats it as fourteen goals per
game. Every club on that list has been in a prediction in the last week —
Real Madrid v Real Sociedad, Bradford v Burnley, Lumphat v Nongrah, and the
Serie A card. Those projections were built on totals used as rates.

`data_guard.py` does not catch it. Those records have no `season` and no
`games`, so the season check reports "age cannot be verified" — a WARNING, not
an error — and the minimum-games check has nothing to compare.

**Three ways out, in order of preference:**

1. Convert the manual store to per-game rates and stamp every record with
   `games`, `season` and `updated`. Then the guard can see it.
2. Delete the manual store and let missing clubs be missing. A refusal is
   better than a wrong number, and that is the rule everywhere else here.
3. Make `get_soccer_team_stats()` refuse any manual record lacking `games` and
   `season`, so the fallback fails closed instead of silently.

Whichever you pick, the field name should differ between a total and a rate.
Two quantities sharing one name is what let this run for weeks.

## 5. Netherlands / Eredivisie cannot be run yet

18 teams, season 2026/2027, updated 2026-08-29 — the data is current. The
problem is volume:

```
Ajax 2g   AZ Alkmaar 3g   Excelsior 2g   Nijmegen 2g   Telstar 2g
Twente 2g   Willem II 2g   ... all 18 between 2 and 3 games
```

The floor is 5. Re-ingesting will not help — those are all the games that have
been played. AZ at 0.333 goals against per game is one clean sheet, not a
defence.

Every European league is in the same position: Premier League, Championship,
Serie A, Serie B, La Liga all 1-3 games in. Liga MX (18 teams) and MLS (30
teams) are further along and runnable.

**The fix is a prior-season blend** — weight this season's thin sample against
last season's finished one, the same `weight = games / (games + K)` idea already
used for regression to the mean, but blending toward the club's own prior season
instead of the league average. Roughly two hours. It unblocks every European
league at once and is the highest-value thing left on the list.
